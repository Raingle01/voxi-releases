## 核心特性

Voxi 重点关注速度、隐私和简洁体验：

- **本地运行：** 语音处理和转写可在本机完成
- **极速实时识别：** 适合高频输入和日常办公场景
- **隐私安全：** 数据无需上传云端，更适合隐私敏感用户
- **完全免费：** 无需注册即可下载和使用
- **桌面体验优先：** 适合日常输入、记录、转写与效率提升
